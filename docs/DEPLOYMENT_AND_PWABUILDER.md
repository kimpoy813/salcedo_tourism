# Deployment, PWABuilder & Google Play Store Guide
## Project CEDO: Turi App — Municipality of Salcedo, Ilocos Sur

---

## 1. Architecture Overview
- **Framework:** Next.js App Router + TypeScript + Tailwind CSS
- **Database:** Drizzle ORM + Neon Serverless PostgreSQL (with automatic local PGlite fallback when `DATABASE_URL` is unset during local development/testing)
- **Media Storage:** Vercel Blob (`BLOB_READ_WRITE_TOKEN`) with safe local `/public/uploads/` fallback in dev
- **Tourist PWA Scope:** `/app/` (`start_url: /app/`, `scope: /app/`, `manifest: /app/manifest.webmanifest`, `sw: /app/sw.js`)
- **Admin Dashboard Scope:** `/admin` and `/admin/login` (strictly excluded from PWA install scope and never cached by the service worker)

---

## 2. Vercel Deployment Steps
1. **Create / Link Project on Vercel:**
   - Import this Git repository (`kimpoy813/salcedo_tourism`) into Vercel.
   - Framework Preset: **Next.js**.
   - Build Command: `npm run vercel-build` (runs `tsx src/db/migrate.ts --if-db && next build`).
2. **Provision Neon Serverless PostgreSQL:**
   - Attach **Neon Postgres** from Vercel Integrations (sets `DATABASE_URL` / `POSTGRES_URL` automatically).
   - Run initial schema migration & seed against production Neon once `DATABASE_URL` is set:
     ```bash
     npm run db:migrate
     npm run db:seed
     ```
3. **Provision Vercel Blob Storage (Optional for Media Uploads):**
   - Enable Vercel Blob in the Vercel Storage tab to set `BLOB_READ_WRITE_TOKEN`.
4. **Configure Environment Variables in Vercel:**
   - `DATABASE_URL` — Neon pooled connection string
   - `AUTH_SECRET` — Minimum 32-character random secret for Admin JWT (`openssl rand -hex 32`)
   - `BLOB_READ_WRITE_TOKEN` — Vercel Blob read/write token
   - `ADMIN_SEED_PASSWORD` / `TOURISM_ADMIN_SEED_PASSWORD` / `EDITOR_SEED_PASSWORD` / `DATA_OFFICER_SEED_PASSWORD` — Override default seed passwords before running `npm run db:seed` in production!
5. **Custom Domain:**
   - Bind your official municipal domain (e.g., `turi.salcedoilocossur.gov.ph`). HTTPS is automatic on Vercel and required by PWABuilder & Android TWA.

## 3. PWABuilder Packaging Readiness (`/app`)
The Tourist PWA lives strictly under `/app/` so installed app users open directly into the mobile-first discovery & itinerary experience, while `/admin` stays outside the app scope.

1. Open [https://www.pwabuilder.com](https://www.pwabuilder.com) and enter your live HTTPS URL:
   `https://<your-production-domain>/app`
2. PWABuilder will validate `/app/manifest.webmanifest`:
   - **Name:** `Project CEDO: Turi App`
   - **Short Name:** `Turi`
   - **Start URL:** `/app/`
   - **Scope:** `/app/`
   - **Display:** `standalone`
   - **Theme Color:** `#123F35`
   - **Icons:** `192x192`, `512x512`, and `512x512` maskable PNGs under `/app/icons/`
   - **Screenshots:** Narrow (`540x960`) and Wide (`1280x720`) PNGs under `/app/screenshots/`
3. PWABuilder will validate `/app/sw.js`:
   - Served with `Service-Worker-Allowed: /app/` and `Cache-Control: no-store`.
   - Offline fallback (`/app/offline`) verified.
   - Explicitly bypasses `/admin` and `/api/*` so personal visitor data and admin state are never cached.
4. Generate the **Android Package (AAB / APK via Trusted Web Activity / Bubblewrap)**.

## 4. Digital Asset Links (`assetlinks.json`) for Android TWA
To remove the browser URL bar inside the Android Play Store TWA app:
1. Obtain the SHA-256 certificate fingerprint from your Google Play App Signing key or upload keystore:
   ```bash
   keytool -list -v -keystore release-key.jks -alias turi
   ```
2. Create `public/.well-known/assetlinks.json`:
   ```json
   [
     {
       "relation": ["delegate_permission/common.handle_all_urls"],
       "target": {
         "namespace": "android_app",
         "package_name": "ph.gov.ilocossur.salcedo.turi",
         "sha256_cert_fingerprints": [
           "YOUR:APP:SIGNING:SHA256:FINGERPRINT:HERE"
         ]
       }
     }
   ]
   ```
3. Verify `https://<your-domain>/.well-known/assetlinks.json` returns HTTP `200` with `application/json`.

## 5. Google Play Store Submission Checklist
- Upload the signed `.aab` generated by PWABuilder / Bubblewrap.
- **Privacy Policy URL:** Link to your hosted RA 10173 privacy notice (`/app/more` or `/api/privacy-notice`).
- **Data Safety Declaration:**
  - Account creation: **Not required** (no tourist login).
  - Location: **Optional**, never forced or collected in background.
  - Visitor Plan Form: Strictly voluntary contact details; origin municipality/province and group size collected only upon final itinerary submission with explicit RA 10173 acknowledgment and unprechecked optional communications consent.
- **App Review Note for Google Play:** Explain that Project CEDO: Turi App provides immediate public tourism access with zero login walls, and admin governance routes (`/admin`) are restricted to municipal staff on the web console.
